# Award Insights

Static site for awardinsights.org. Four self-contained HTML pages; no build step.

- `index.html` — landing page
- `nsf.html` — NSF Award Insights
- `designations.html` — Research Activity Designations
- `portfolio.html` — Research Portfolio Trends

Hosted with GitHub Pages from the main branch. `CNAME` holds the custom domain.
To update a tool, replace its HTML file and commit.
